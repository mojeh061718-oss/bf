# Game Concepts — iPhone PWA, Built for Week-Two Retention

Ten fully developed concepts for a touch-first iPhone PWA game with high return playability after 2+ weeks. Six grow directly from the founder's seed ideas; four are team originals. Every document follows the same template (pitch → fantasy → core loop → session shape → retention systems → content ceiling → PWA feasibility → complexity → team verdict) so they compare cleanly.

**Shared design constraints honored by all ten:**
- One-thumb-friendly touch controls; sessions that fit pockets (2–15 min) but can stretch.
- A concrete day-14+ answer (dailies, seasons, leaderboards, mastery, UGC — named per concept).
- PWA-honest: 2D rendering, offline-capable cores, light backends, iOS 16.4+ web push for installed PWAs, no real-money mechanics anywhere.

## The Team's Ranking Rationale

We scored against the founder's stated priority — **high return playability after two weeks** — weighted by confidence-per-effort and PWA honesty.

- **Safest retention bets:** **#08 Hexen Draft** (the genre's day-30 curves are industry-proven; our job is an original core, and we have one) and **#02 Trickshot Open** (daily course + ghost replays + divisions is the cheapest proven comeback loop we can build).
- **Highest ceilings if we commit:** **#04 The Bracelet** (smart-AI poker career is an underserved niche with a real engineering moat — biggest build, biggest defensibility) and **#03 From Nothing** (the only concept players will tell *stories* about; the retention is emotional, the cost is a permanent writers' room).
- **Best expression of the seed ideas:** #01/#06 for physics (ship at most one — same audience; #01 has the better *moment*, #06 the better *endgame*), #05 for pure skill (fastest to prototype — two weeks of playtesting tells us if it's special).
- **Charming dark horses:** #07, #09, #10 — lighter builds, loyal-niche retention, each with one signature system (seeded seasonal economy / legacy careers / knowledge meta) that could be borrowed by a front-runner even if not chosen.

**Recommended next step:** shortlist 2–3, prototype the *riskiest single interaction* of each (Trickshot's flick, Threshold's drag-feel, Dead Load's thumb-building, The Bracelet's AI table), then commit. Concept docs are cheap; feel is the truth.
