# Vendored texture assets — licenses

All three textures below were fetched from **ambientCG** (https://ambientcg.com),
which publishes all of its assets under the **Creative Commons CC0 1.0 Universal
license** (public domain dedication — no attribution required; verified at
https://docs.ambientcg.com/license/ at time of download, 2026-07-16).

Each file is the `_Color` map from the 1K-JPG pack, downscaled to 512×512 and
recompressed. Originals were not committed.

files are served same-origin alongside the rest of `docs/`.
